# Frontend Developer CV

A modern, responsive, and print-friendly personal CV built from scratch using HTML5 and CSS3.

This project presents my technical skills, featured frontend projects, professional experience, education, and career goals in a clean, structured layout.

## Live Preview

[View My CV](https://johnyisbackk.github.io/frontend-developer-cv/)

## Features

- Modern and minimal CV design
- Responsive layout for desktop, tablet, and mobile
- Clean two-column layout using CSS Grid and Flexbox
- Featured frontend projects with Live Demo and GitHub links
- Technical skills and current learning goals
- Professional experience and education
- Print-friendly A4 layout with custom print styles
- No JavaScript or external UI frameworks required

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries
- Google Fonts (Inter)
- Git & GitHub

## Getting Started

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No installation or build process is required.

## Printing the CV

The project includes custom print styles optimized for A4 paper.

To export it as a PDF:

1. Open the CV in your browser.
2. Press `Ctrl + P`.
3. Select **Save as PDF**.
4. Choose A4 paper size.
5. Enable background graphics.
6. Check the preview and save.
